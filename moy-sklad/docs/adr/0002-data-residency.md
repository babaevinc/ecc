# ADR 0002 — Где хранить данные

- Статус: **предложено, ждёт решения владельца**
- Дата: 2026-11-01

## Контекст

В базе будут персональные данные сотрудников (имя, телефон или email). По 152-ФЗ при сборе
персональных данных граждан РФ их запись, систематизация и хранение должны вестись в базах на территории
России. Это не юридическая консультация: окончательное решение лучше подтвердить у юриста.

## Варианты

| Вариант | Плюсы | Минусы | Ориентир затрат |
|---|---|---|---|
| A. Supabase Cloud (регион ЕС) | Быстрый старт, обновления и резервные копии — у Supabase | Данные за рубежом — риск по 152-ФЗ; оплата картой из РФ может не пройти | Бесплатно на старте, далее от 25 $/мес |
| B. Supabase на российском облаке (Yandex Cloud, Selectel и др.) | Данные в РФ; тот же Supabase и тот же код | Обновления, резервные копии и мониторинг — на нас (`dev-devops`) | Сервер 2–4 vCPU, 4–8 ГБ ОЗУ — уточнить по прайсу провайдера |
| C. Российская управляемая PostgreSQL + своя аутентификация | Данные в РФ, базу обслуживает провайдер | Auth, push, cron писать и защищать самим — больше кода и рисков | Зависит от провайдера |

## Рекомендация

**B** — Supabase в российском облаке. Код и тесты те же, что для варианта A; данные остаются в РФ.
Для разработки и CI используется локальный Supabase (`npx supabase start`) — решение на них не влияет.

## Что нужно от владельца

1. Выбрать вариант (A, B или C).
2. Для B: выбрать провайдера и создать аккаунт (данные доступа в чат не присылать).
3. По возможности — подтвердить у юриста требования 152-ФЗ для вашего случая.
