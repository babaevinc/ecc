# «Мой склад» — требования к первой версии (MVP)

Источник: рабочее веб-приложение «Мой склад», которым компания уже пользуется, и пожелания владельца.
Первая версия мобильного приложения переносит то, что работает, и добавляет вход по логину и паролю,
push-уведомления и супер-админа.

## Кто пользуется

Оптово-розничная компания по продаже зелени: два холодильных склада и точка на рынке (Екатеринбург).
Сотрудники работают с телефона, часто одной рукой и в перчатках.

## Обязательно в MVP

| № | Функция | Критерий приёмки |
|---|---|---|
| R1 | Вход по логину (email или телефон) и паролю, выход, восстановление пароля | Неверный пароль 5 раз за 5 минут блокирует вход на 5 минут; ошибка не раскрывает, существует ли логин |
| R2 | Компании и роли: супер-админ, владелец, кладовщик, менеджер, наблюдатель | Права совпадают с матрицей в `docs/architecture/roles.md`; данные одной компании недоступны другой |
| R3 | Склады и точка на рынке, ассортимент (коробки или кг), порядок по важности | Владелец добавляет, архивирует и сортирует; удалить можно только позицию без истории |
| R4 | Приход партиями: склад, дата, зелень, количество, поставщик, закупочная цена | Остаток растёт сразу; цену видит только владелец |
| R5 | Остатки по складам и партиям, сортировка по количеству, возраст партии | Партии старше 5 дней подсвечены, старше 7 — в уведомлениях |
| R6 | Заявки: создание, резерв, «в обработке», отгрузка (FIFO или выбранная партия), отмена с подтверждением | Отгрузка списывает со старых партий; закрытую заявку нельзя отгрузить повторно |
| R7 | Продажа без заявки, отметка «уценка» | Списывает FIFO; отмена возвращает товар |
| R8 | Перемещение между складами с сохранением даты партии | Возраст партии не обнуляется |
| R9 | Списание порчи с причиной без пересчёта; пересчёт склада с утверждением владельцем | Нельзя списать больше остатка; отменить может автор в тот же день или владелец |
| R10 | Цены продажи на день | Подставляются в заявки и продажи; прошлые операции не меняются |
| R11 | История операций: кто, что, когда | Каждое изменение остатка видно в истории |
| R12 | Push-уведомления: новая заявка, заявка отгружена или отменена, партия старше 7 дней | Приходят при закрытом приложении; свои действия не уведомляют |
| R13 | Удаление аккаунта из приложения | Требование App Store для приложений с регистрацией |

## После MVP

Финансы и долги клиентов (главная денежная проблема бизнеса — долги до 80 % оборота), выгрузка в Excel,
сводка дня, работа без сети.

## Ограничения

- Данные сотрудников — персональные данные (152-ФЗ): где их хранить, решается в ADR 0002.
- Дизайн в стиле iOS, светлая и тёмная тема, крупные зоны нажатия, кнопки −/+ для количества.
- Одно действие — одно нажатие; ввод количества не должен «съедать» нажатие кнопки.
